# Information Security Policy
All laptops must use full-disk encryption. Passwords must be at least 14 characters and multi-factor authentication is mandatory for all SaaS applications.

## Incident reporting
Suspected security incidents must be reported to the security operations centre within 1 hour via the #sec-incident channel or the ITSM portal.

## Data classification
Data is classified as Public, Internal, Confidential or Restricted. Restricted data must never be pasted into external AI tools.
